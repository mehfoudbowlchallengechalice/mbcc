Deploy MBCC using Google Cloud Console

1. Open https://console.cloud.google.com/?project=project-72f15f51-cfef-4c90-b6e
2. Click Activate Cloud Shell (>_) in the upper-right toolbar.
3. Use the Cloud Shell three-dot menu > Upload and upload mbcc-cloudrun.zip
   to your Cloud Shell home directory.
4. Paste these commands into Cloud Shell:

   unzip -o ~/mbcc-cloudrun.zip -d ~/mbcc-cloudrun
   cd ~/mbcc-cloudrun
   bash cloudrun/update-live-source.sh

5. If Google asks to authorize Cloud Shell, review and authorize it yourself.
6. Keep the tab open while Google builds and deploys the service.
7. The script prints your app connection URL and checks the real spreadsheet
   response. If an error occurs, share the error text in the chat.

This updates the existing mbcc-api service using its existing reader/build identities.

The Google account running these steps needs permission to deploy source updates
using the existing service accounts. For a brand-new service, use cloudrun/deploy.sh
instead; it performs the original API/IAM setup.
